#Calculator Project Read Me file (Introduction/Summary)

A calculator deveoped with Python3 used from the terminal (CLI), built within SCM4910 (DevOps)

#What will the project do
1. Add numbers together
2. Subtract numbers together
3. Multiply numbers together
4. Divide numbers together
5. Display the result

#How it can be run
Run: ./run.sh

#How to test (automated)
Run: ./check.sh (python3 pytest install it)

#How to stop
Stop: Ctrl + C

Enter a first number, then operator (+, -, /, *), and then the second number
The program will print Total: followed by the result
